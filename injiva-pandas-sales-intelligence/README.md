# injiva-pandas-sales-intelligence

**INJIVA Digital Systems · Data & Analytics Department**
Assessment **INJIVA-DS-DA-PANDAS-001**: Advanced Retail Sales Intelligence, Data Quality Engineering,
Financial Analytics and Git/GitHub Version Control.

## Purpose

ZimTech Retail Holdings (a fictional Zimbabwean retailer) stores sales in a Python dictionary that contains
deliberate data quality problems. This project turns that dictionary into a validated, cleaned and
analysed dataset using a reproducible, tested **Pandas/NumPy pipeline**. Every data issue is documented,
and nothing is invented or deleted silently.

No visualisation libraries are used (assessment restriction). Results are delivered as DataFrames, CSV files
and a written management report.

## Headline results

| Metric | Value |
|---|---|
| Valid / rejected transactions | 17 / 3 |
| Net revenue | $13,340.50 |
| Gross profit | $3,255.50 |
| Overall gross profit margin | 24.40 % |

The full findings are in [`reports/management_report.md`](reports/management_report.md).

## Installation

Requires **Python 3.10+**.

```bash
git clone https://github.com/<your-username>/injiva-pandas-sales-intelligence.git
cd injiva-pandas-sales-intelligence

python -m venv .venv
# Windows (PowerShell):  .venv\Scripts\Activate.ps1
# macOS / Linux:         source .venv/bin/activate

pip install -r requirements.txt
```

## Running

Run all commands from the **project root** folder.

| Task | Command |
|---|---|
| Run the full pipeline (regenerates `data/*.csv`) | `python -m src.pipeline` |
| Run the automated tests | `python -m pytest -v` |
| Open the notebook | `jupyter lab notebooks/sales_analysis.ipynb` → *Kernel → Restart & Run All* |

## Key cleaning decisions

| Problem | Decision | Why |
|---|---|---|
| `keyboard`, `LAPTOP`, `monitor` | Standardise to Title Case | Same product, different spelling |
| Mixed date formats | Explicit formats; `DD/MM/YYYY` and `DD-MM-YYYY` read day-first | All data is from January 2026; no guessing |
| TX012 missing price | **Reject** for manual review | Imputing would invent revenue |
| TX009 quantity −2 | **Reject** for manual review | Could be a return, but no original-sale reference |
| TX015 quantity 0 | **Reject** | No goods sold |
| Masvingo has no rows | Report as *unknown*, not zero | Absence of records ≠ zero sales |

The full list of assumptions (A1–A7) is in the docstring of `src/cleaning.py`.

## Limitations

- Only 17 valid transactions over 20 days, so results are indicative, not statistically conclusive.
- Each salesperson works in only one city, so salesperson and city effects cannot be separated.
- No overhead data, so only **gross** profit (not net profit) is reported.
